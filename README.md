# kaomojimaker（かおもじメーカー）

パーツを選んで、自分だけの顔文字（かおもじ）を組み立てられるツールです。

## できること

- パーツをクリックして選ぶだけで、顔文字がリアルタイムに組み上がります
  - 輪郭（10種）／目（13種）／口（13種）／頬・照れ（9種）／腕・手（8種）／装飾（10種）
- 「ランダム」ボタンで全パーツをランダムに組み替え
- 「コピー」ボタンで完成した顔文字をクリップボードへコピー
- 「お気に入りに保存」で好きな顔文字を保存（ブラウザの localStorage にのみ保存され、サーバーには送られません）。クリックで読み込み、×で削除
- プリセットの顔文字をクリックすると、その組み合わせを読み込めます

## 使い方

1. ページを開く
2. 各カテゴリのパーツチップをクリックして選ぶ（プレビューが即座に更新されます）
3. 気に入ったら「コピー」でコピー、または「お気に入りに保存」で残しておく

## 技術

- Python / Flask の単一ファイルアプリ（`app.py`）
- 組み立て・ランダム・コピー・お気に入りのロジックはすべてブラウザ側の JavaScript で動作し、サーバー側に状態を持ちません
- 起動: `gunicorn app:app`（開発時: `python app.py`）

## テスト

```bash
python -m pytest tests/ -q
```
